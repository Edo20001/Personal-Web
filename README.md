# Personal Web — Zenith Dashboard

Dashboard pribadi satu halaman (HTML, CSS, dan JavaScript tanpa framework) untuk mengelola mood, pernapasan, brain dump, jadwal kuliah dan mengajar, serta timer fokus dengan suara latar.

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Struktur
- `index.html` — seluruh aplikasi
- `audio/` — suara latar (`lofi-pad.mp3`, `hujan.mp3`, `ambient.mp3`)

Data jadwal, mood, dan draf tersimpan di `localStorage` browser.
